# 大埔南北候选路径案例

本目录为 2026-11-24 工作台导入南北方案 KML 后生成的 48 页核查稿。两条线按大埔电厂至嘉应站方向统一里程，北方案 41.839 km，南方案 43.273 km。报告覆盖 3.3、3.4.8 至 3.4.11 和 3.5，使用行政区划、地物、DEM 和该案例的初设对照资料。

两方案均有冲突待复核；南方案合规部分在模型调用失败后依据核查事实生成。使用相同线位进行核查时，可对照 run_summary.json 中的 KML 文件哈希。复现需另行交接工程地图、源数据、KML 和案例专用补充资料。
