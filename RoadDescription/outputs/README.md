# 报告输出目录

| 要找什么 | 位置 |
| --- | --- |
| 工作台最近一次产齐的完整报告 | `最近成稿/完整报告.pdf`、`最近成稿/完整报告.docx` |
| 最近一次的路径描述、方案比选、南北合规分册 | `最近成稿/` 内对应的 PDF 和 Word，共五对文件 |
| Git 中发布的固定大埔样例 | `latest/`，版本和资料范围见该目录的 README |
| 每个导入任务的原始报告、地物证据、模型记录与审校草稿 | `workbench_jobs/<任务ID>/` |
| 坐标规划任务、KML 工作台种子地图 | `report_jobs/`；种子由配置的 `output_dir` 指定，本机为 `大埔南北候选线_20261124/`，公开模板为 `kml_seed/` |
| 本地以往实验与验收资料 | `archive/runs/` 放原运行目录，`archive/logs/` 放日志，`archive/packages/` 放旧交付压缩包 |

工作台任务产齐五对文件且进入“生成完成”或“待复核”后，会自动更新“最近成稿”。这里是指向原件的相对符号链接，文件是否通过审阅可在前端查看。工作台中单独保存的段落修订仍从“审校版”导出。

旧报告可直接从归档目录打开。部分历史 JSON、配置和验收脚本记录了整理前的绝对路径。需要执行此类命令时，在项目根目录加上以下前缀，命令运行期间会临时恢复原目录入口，结束时收回快捷入口。原路径和归档位置也可查本机 `archive/目录迁移.json`。

```bash
.venv/bin/python tools/with_archived_outputs.py .venv/bin/python tools/check_acceptance_results.py
```
