# 大埔南北候选路径案例

本目录为 2026-11-25 工作台导入南北方案 KML 后生成的 48 页核查稿。两条线按大埔电厂至嘉应站方向统一里程，北方案 41.839 km，南方案 43.273 km。报告覆盖 3.3、3.4.8 至 3.4.11 和 3.5，使用行政区划、地物、DEM 和该案例的初设对照资料。

[综合报告 PDF](大埔南北候选路径综合分析.pdf) · [可编辑 Word](大埔南北候选路径综合分析.docx) · [路径总图](图3.3-1_区域高亮.jpg)

三个智能体均使用 Claude Sonnet 4.6 组织正文，地图以工程 GIS 数据绘制。两方案均有冲突待复核。全流程共 106 项模型审阅，其中 45 项调用失败，另有 1 项阻断意见，样例保留为核查稿。使用相同线位进行核查时，可对照 run_summary.json 中的 KML 文件哈希。复现需另行交接工程地图、源数据、KML 和案例专用补充资料。
